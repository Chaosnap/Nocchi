# 安装

Nocchi 需要 **macOS 14 Sonoma 或更新的系统**，Apple 芯片和 Intel 的 Mac 都可以。每个版本都由 GitHub Actions 构建，连同 `SHA256SUMS.txt` 一起发布在 [Releases](https://github.com/Chaosnap/Nocchi/releases/latest) 页面。

| 系统 | 文件 |
| --- | --- |
| macOS 14 或更新（通用） | `Nocchi-macOS-<版本>.zip` |
| iPhone | 正在做：灵动岛就是出片口 |

打开之前先核对一下下载的文件：

```bash
shasum -a 256 Nocchi-macOS-*.zip
```

解压后把 **Nocchi.app** 拖进「应用程序」文件夹。

## 现在的版本还没有公证

公证需要付费的 Apple 开发者证书，项目暂时还没有，所以构建是 ad-hoc 签名，macOS 第一次会拦一下。在「终端」里运行：

```bash
xattr -dr com.apple.quarantine /Applications/Nocchi.app
```

或者先打开一次 Nocchi，再到「系统设置 → 隐私与安全性」里点「仍要打开」。

## 第一次用

界面默认是简体中文。想用英文：<kbd>⌘,</kbd> 打开设置 → 通用 → 语言，把「界面语言」选成 English，按提示重新打开。

1. Nocchi 住在菜单栏（光圈图标）、程序坞和刘海里。程序坞图标可以在「设置 → 通用」里关掉。
2. **把鼠标移到刘海上**，相机面板就展开了：屏幕快门、自拍、大头贴、冲印照片，还有装着的胶卷和相纸。
3. 按 <kbd>⌃⌥⌘S</kbd>，在屏幕上框一块，它就会冲印成一张相片从刘海里出来。
4. 等大约 15 秒让它显影，或者拿起相片甩一甩。
5. 双击相片打开装饰台；按 <kbd>⌘0</kbd> 打开相册。

::: tip 没有刘海？
在没有刘海的 Mac 和显示器上，Nocchi 会在屏幕顶部正中画一个小小的虚拟刘海，用法完全一样。
:::

## 权限

每个权限都在第一次用到时才问，而且是在屏幕上出现任何 Nocchi 的覆盖层之前问，系统弹窗永远不会被挡住。

| 权限 | 什么时候问 |
| --- | --- |
| 摄像头 | 打开自拍取景器、大头贴机，或者在设置里预览摄像头 |
| 屏幕录制 | 用屏幕快门 |
| 桌面、文稿、下载 | 打开「接管系统截图」 |

什么都不会上传，见 [隐私与安全](./privacy)。
