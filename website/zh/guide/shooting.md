# 拍照

把鼠标移到刘海上，它就展开成相机面板。不管用哪种方式拍，结局都一样：一张相片从刘海里吐出来，开始显影。

![鼠标移到刘海上展开的相机面板](/screenshots/notch-panel.jpg)

## 屏幕快门

按 <kbd>⌃⌥⌘S</kbd>，或者点面板里的「屏幕快门」，在屏幕上框选任意一块。框下来的画面会用装着的胶卷、选好的相纸冲印出来。

### 接管系统截图

在「设置 → 通用」里打开「接管系统截图」，你用 <kbd>⇧⌘3</kbd>、<kbd>⇧⌘4</kbd> 截的图也会冲印成相片。Nocchi 会留意截图文件夹里的新文件，所以第一次 macOS 会问能不能访问那个文件夹。默认是关的。

## 自拍

按 <kbd>⌃⌥⌘F</kbd>，或者点「自拍」。刘海里会长出一个带实时画面的取景器。按 <kbd>Space</kbd> 或快门键拍照，<kbd>Esc</kbd> 取消。默认会倒数 3 秒，拍的时候屏幕闪一下白光当补光。

## 冲印已有的照片

- **把图片拖到刘海上。** 从 Finder 拖着文件靠近刘海，它会变成投放区，松手就冲印。
- **文件**：<kbd>⌘O</kbd>，或者面板里的「冲印照片」，一次最多选 20 张。
- **照片**：<kbd>⇧⌘O</kbd> 打开系统的照片选择器。Nocchi 只拿得到你选中的那几张，碰不到图库里的其他照片。

每一张都用装着的胶卷和选好的相纸冲印，一张接一张从刘海里出来。

## 用哪个摄像头

「设置 → 摄像头」里列出内建摄像头、外接摄像头、以摄像头扩展形式安装的虚拟摄像头（OBS、Camo 等）和 iPhone 的连续互通相机，带实时预览和镜像开关。选中的摄像头被拔掉时，Nocchi 会自动换回默认摄像头。

## 任何时候都能离开

覆盖层绝不会把你困住：摄像头权限在任何东西盖住屏幕之前就问好；每个覆盖层都有看得见的出口，也都认 <kbd>Esc</kbd> 和 <kbd>⌘Q</kbd>；摄像头几秒没反应，拍照就会超时放弃。
