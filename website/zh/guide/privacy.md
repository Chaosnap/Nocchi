# 隐私与安全

Nocchi 是一台住在刘海里的相机，**完全在你的 Mac 上运行**：

- 从不联网，不上传、不同步任何照片或数据；
- 没有账号，没有统计、广告或崩溃上报；
- 不收集任何个人信息。

## 权限

| 权限 | 什么时候 | 用来做什么 |
| --- | --- | --- |
| 摄像头 | 自拍取景器、大头贴机，或在设置里预览摄像头 | 拍照。只在这些界面打开时运行；大头贴机里要按下「开始」才打开 |
| 屏幕录制 | 屏幕快门 | 调用系统的框选截图，再冲印出来 |
| 桌面 / 文稿 / 下载 | 只有打开「接管系统截图」后 | 读取你刚截的图 |
| 照片 | 「从『照片』图库冲印」 | 系统的照片选择器，Nocchi 只拿到你选中的那几张 |

## 照片存在哪里

| 位置 | 内容 |
| --- | --- |
| `~/Pictures/Nocchi/<年-月>/` | 带白边的成片（JPEG） |
| `~/Library/Application Support/Nocchi/` | 照片记录（题字、贴纸、涂鸦、地点、标签）、底片、导入的 LUT |
| App 的偏好设置 | 机身、胶卷、相纸、模板、摄像头等设置 |

想删除所有数据：退出 Nocchi，删掉上面两个文件夹。把相片「移到废纸篓」时，成片进废纸篓（还能捡回来），记录和底片会被删除。

## 覆盖层不会把你困住

权限在任何覆盖层出现之前就问好；覆盖层都在菜单栏之下；每个覆盖层都有看得见的出口，也都认 <kbd>Esc</kbd> 和 <kbd>⌘Q</kbd>；等摄像头的步骤都会超时。

## 报告漏洞

请通过 GitHub 私下报告安全问题：在 [仓库](https://github.com/Chaosnap/Nocchi/security/advisories/new) 里点 *Security → Report a vulnerability*。详见 [安全政策](https://github.com/Chaosnap/Nocchi/blob/main/SECURITY.md)。
