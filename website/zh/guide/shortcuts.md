# 快捷键

## 在哪里都能用

| 按键 | 作用 |
| --- | --- |
| <kbd>⌃⌥⌘S</kbd> | 屏幕快门 |
| <kbd>⌃⌥⌘F</kbd> | 自拍 |
| <kbd>⌃⌥⌘B</kbd> | 大头贴机 |

## Nocchi 在前台时

| 按键 | 作用 |
| --- | --- |
| <kbd>⌘O</kbd> | 从文件冲印照片 |
| <kbd>⇧⌘O</kbd> | 从「照片」图库冲印 |
| <kbd>⌘0</kbd> | 打开相册 |
| <kbd>⌘1</kbd> – <kbd>⌘4</kbd> | 软木板、卡片盒、胶卷、日历 |
| <kbd>⌘F</kbd> | 搜索相册（<kbd>Esc</kbd> 清空） |
| <kbd>⌘,</kbd> | 设置 |
| <kbd>⌘Q</kbd> | 退出 |

## 自拍

| 按键 | 作用 |
| --- | --- |
| <kbd>Space</kbd> | 拍照 |
| <kbd>Esc</kbd> | 取消 |

## 大头贴机

| 按键 | 作用 |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | 上一款 / 下一款相框 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 四格条 / 四宫格 |
| <kbd>Return</kbd> | 投币开始 |
| <kbd>Esc</kbd> | 离开大头贴机 |
| <kbd>⌘Q</kbd> | 离开并退出 |

## 装饰台

| 按键 | 作用 |
| --- | --- |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 撤销 / 重做 |
| <kbd>⌫</kbd> | 删除选中的贴纸 |
| <kbd>Esc</kbd> | 取消选中 |
| <kbd>⌘S</kbd> | 完成 |
