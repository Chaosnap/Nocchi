# 装饰台

## 桌面上随手写

在桌面相片上点右键：

- **在白边上写字**：用触控板写，笔画粗细跟着压力走。写完选「写完了」。
- **写一句题字…**：白边上打一行字。默认题字是「我可以见你吗？」，可以在「设置 → 相纸」里改。
- **印上日期 / 不印日期**，以及 **擦掉笔迹**。

## 装饰台

双击相片，或者右键选「装饰…」。在相册的每一种看法里也一样。也可以让它在每张相片显影完成时自己打开：「设置 → 相纸 → 显影完成后自动打开装饰台」。

![装饰台](/screenshots/decorate.jpg)

一张深色胡桃木桌，一盏暖色台灯。你做的一切都和照片一起存着，不会烧死在成片里：模板、贴纸、笔迹随时能改，按「完成」会从底片重新合成成片。

### 工具（左边）

一个皮革托盘：选择、**钢笔**、**马克笔**、**油性蜡笔**（暗房里在印样上圈片用的那种）、**漆笔**（不透明，能在深色照片上写白字、金字）、**橡皮**（点哪条笔画就擦哪条）。8 个珐琅颜色、三档粗细、撤销与重做。照片上和白边上都能画。

### 贴纸

六个抽屉的印刷品贴纸，全部由 Nocchi 自己画：乙烯 **徽章**（太阳、下雨、咖啡、小狗、小猫、珐琅爱心、相机、胶卷……）、**橡皮章**（带日期的邮戳、OK!、LOVE、「已显影」、红色「珍藏」印章……）、**旧物**（电影票、邮票、价签、行李牌、胶片、小票、火柴盒标）、**纸胶带**、可以自己打字的 **凸字标签**、**模切表情**。拖动贴纸移动它，角上的手柄缩放和旋转；能写字的贴纸会出现文字框，有的能换色，都能翻转、置顶、删除。

### 模板

适用于这种相纸的全部模板，用你自己的照片实时预览。

### 文字

题字 / 心情；题字字体（手写、打字机、铅字）；拍摄的日期和时间（可以改）以及要不要印日期；地点；标签（建议标签或自己写）。可以选择把标签和地点印在白边上，还能给认识的标签自动配一枚小贴纸（#阳光 配太阳徽章，#咖啡 配咖啡杯）。

### 分享

一张 1080 × 1350 的海报：相片放在亚麻、胡桃木、牛皮纸、丝绒、软木、70 年代条纹、晴空或暗房红光上，居中、微斜或两张叠放，右下角可以加一行小字。导出成 JPEG 或 PNG、拷贝，或者直接分享。

### 快捷键

<kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> 撤销与重做，<kbd>⌫</kbd> 删除选中的贴纸，<kbd>Esc</kbd> 取消选中，<kbd>⌘S</kbd> 就是「完成」。
