# 大头贴机

按 <kbd>⌃⌥⌘B</kbd>，或者点刘海面板里的「大头贴」。

1. **布帘落下。** 一幅打褶的剧院暗红丝绒布帘带着金穗帷幔盖住屏幕，还会轻轻摆动。（如果 Nocchi 还没有摄像头权限，macOS 会先问，问完才拉帘。）
2. **选相框。** 布帘后面立着一台胡桃木配黄铜的大头贴机，顶上一圈灯泡，橱窗里挂着这一款相框的样张。
3. **投币。** 按下会发光的「开始」。这时摄像头才打开。
4. **请看镜头！** 然后 3、2、1，白光一闪，一共四次。
5. **布帘拉开**，一条大头贴从刘海里出来。

![丝绒布帘后面，在黄铜橱窗里选相框](/screenshots/booth.jpg)

## 选相框

- **相框**：两边的黄铜箭头（或 <kbd>←</kbd> <kbd>→</kbd>）在 11 款相框之间切换。先是六款大头贴主题：老照相亭（底下印着编号）、黑白照相亭、情人节（心形窗口和蕾丝花边）、金星（墨蓝纸上的烫金小星）、生日快乐（三角彩旗）、新年快乐（朱红纸、金色字）；再是适合大头贴相纸的通用模板：经典、炭黑、牛皮纸、胶片框、70 年代条纹。
- **四格条 / 四宫格**：一个镀铬拨杆在竖条和 2 × 2 之间切换（或 <kbd>↑</kbd> <kbd>↓</kbd>）。每一款相框两种版式都有。
- **黑白 / 彩色**：另一个拨杆。黑白用「照相亭黑白 400」，装着黑白卷时就用它；彩色用「闪光 400」，装着你自己挑的彩色卷时就用它。用哪卷胶卷写在拨杆下面。
- <kbd>Return</kbd> 开始，<kbd>Esc</kbd> 离开。

样张和真正的成片是同一套代码合成的，看到的就是印出来的样子。这次的选择会记住，下次从这里开始；也可以在「设置 → 相纸」里改。

## 离开

任何时候都能走：左上角的「离开大头贴机」按钮、<kbd>Esc</kbd>、<kbd>⌘Q</kbd> 都行。布帘在菜单栏之下，菜单栏里的「退出」永远点得到。选相框的时候不会超时；按下「开始」之后，万一出了问题，一分钟后会自动收起。
