# Shortcuts

## Anywhere

| Keys | Does |
| --- | --- |
| <kbd>⌃⌥⌘S</kbd> | Screen shutter |
| <kbd>⌃⌥⌘F</kbd> | Selfie |
| <kbd>⌃⌥⌘B</kbd> | Photo booth |

## When Nocchi is in front

| Keys | Does |
| --- | --- |
| <kbd>⌘O</kbd> | Print photos from files |
| <kbd>⇧⌘O</kbd> | Print photos from Photos |
| <kbd>⌘0</kbd> | Open the album |
| <kbd>⌘1</kbd> – <kbd>⌘4</kbd> | Corkboard, card box, film, calendar |
| <kbd>⌘F</kbd> | Search the album (<kbd>Esc</kbd> clears it) |
| <kbd>⌘,</kbd> | Settings |
| <kbd>⌘Q</kbd> | Quit |

## Selfie

| Keys | Does |
| --- | --- |
| <kbd>Space</kbd> | Take the picture |
| <kbd>Esc</kbd> | Cancel |

## Photo booth

| Keys | Does |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | Previous / next frame |
| <kbd>↑</kbd> <kbd>↓</kbd> | Four-frame strip / 2×2 grid |
| <kbd>Return</kbd> | Drop the coin and start |
| <kbd>Esc</kbd> | Leave the booth |
| <kbd>⌘Q</kbd> | Leave and quit |

## Decorating desk

| Keys | Does |
| --- | --- |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | Undo / redo |
| <kbd>⌫</kbd> | Delete the selected sticker |
| <kbd>Esc</kbd> | Deselect |
| <kbd>⌘S</kbd> | Done |
