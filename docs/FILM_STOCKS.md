# 胶卷

26 卷内置胶卷，名字与参数全部原创，定义在 `Packages/NocchiKit/Sources/NocchiKit/Resources/FilmStocks.json`（由 `scripts/film/make_stocks.py` 生成）。影调参考了经典胶片的风格，但不使用任何品牌名（CLAUDE.md §4）。

胶卷柜按 `tags` 分组（`FilmStock.family`）：即显相纸 / 彩色负片 / 夜景与电影 / 黑白 / 大头贴 / 自定义 LUT。`tags` 里的 `mini`、`wide`、`instant`、`print`、`booth` 决定推荐相纸（`FilmStock.recommendedFormat`）。

## 配方字段

```json
{
  "tone": {
    "exposure": 0.1,            // 曝光（档）
    "temperature": 0.25,        // -1 冷 … +1 暖
    "tint": -0.05,              // -1 绿 … +1 品红
    "contrast": 1.05,           // 以 0.5 为支点的 S 曲线
    "saturation": 0.9,          // 保亮度的饱和度，> 1 时平滑逼近色域边界，不会把颜色糊死
    "crossTalk": 0.04,          // 染料串色
    "curves": {                 // 每通道单调三次曲线（[x, y]，0…1），没写的端点自动补 (0,0)/(1,1)
      "master": [[0, 0.04], [0.25, 0.23], [0.5, 0.51], [0.75, 0.79], [1, 0.98]],
      "b": [[0, 0.05], [0.5, 0.47], [1, 0.9]]
    },
    "hsl": {                    // 八个色相带：red orange yellow green cyan blue purple magenta
      "green": { "hue": -15, "saturation": 0.86, "luminance": 0.02 }
    },
    "shadowTint": "#5A7A6A", "shadowTintAmount": 0.35,      // 分离色调（只改颜色、不改明暗）
    "highlightTint": "#F2D9A8", "highlightTintAmount": 0.35,
    "fade": 0.04,               // 阴影雾化（越暗抬得越多）
    "highlightRolloff": 0.5,    // 高光软肩：过曝的地方柔和过渡而不是硬切
    "skinProtect": 0.4,         // 肤色（橙色带）少跟随整体饱和度变化
    "blackLift": 0.06, "whiteCap": 0.96,                    // 抬黑 / 压白
    "monochrome": false, "monoMix": [0.3, 0.59, 0.11],      // 黑白与通道混合
    "monoTone": "#C8A880", "monoToneAmount": 0.35           // 黑白调色
  },
  "effects": { "grain": 0.18, "grainSize": 1.2, "halation": 0.1, "bloom": 0.15, "vignette": 0.25, "lightLeak": 0, "edgeSoftness": 0.45 },
  "paper": { "color": "#F6F2E8", "ink": "#2B2A28" }
}
```

处理顺序：线性空间（曝光 → 白平衡 → 串色 → 高光软肩）→ gamma 空间（反差 → 曲线 → HSL → 饱和度 / 肤色保护 → 分离色调 → 雾化 → 抬黑压白）。黑白胶卷在线性空间按 `monoMix` 混成灰度，再走反差、曲线和调色。

所有字段都可以省略（省略即默认、即不改变）。配方在运行时烘焙成 33³ 的 3D LUT 交给 Core Image；任意胶卷都可以在 Mac 设置里导出成 `.cube`。

## 调色工具（只在本机看效果，不构建 App）

- `scripts/film/make_stocks.py`：所有胶卷的配方源，运行后写出 `FilmStocks.json`。
- `scripts/film/preview_looks.py`：配方数学的 numpy 移植（与 `ToneRecipe.swift`、`ColorMath.swift` 逐函数对应），把每卷胶卷套到测试照片上拼成联系表。用 Blender 自带的 Python（带 numpy 与 OpenImageIO）运行：

```bash
PY=$(ls /Applications/Blender.app/Contents/Resources/*/python/bin/python3* | head -1)
$PY scripts/film/preview_looks.py chart --out /tmp/film/chart.png
$PY scripts/film/preview_looks.py sheet --out /tmp/film/contact.png --rows-per-page 9 /tmp/film/chart.png photo1.png photo2.png
```

测试照片放在仓库外（可以用 `sips -s format png` 把系统自带的图片转出来），不要提交第三方图片。改 Swift 里的色彩数学时同步改 Python 版。

## 自定义胶卷

Mac：设置 → 胶卷 → 「导入 .cube 胶卷…」。导入时检查文件大小（≤32 MB）、格点数、数据行数、数值是否有限；1D LUT 和非 0…1 定义域会自动重采样。
