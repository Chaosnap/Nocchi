## 2026-11-24

### D33 · 产品文档站 + CI 截图
- 仓库所有者：参考 Typewriter Nocturne 的产品网页，「用 github ci 收集些截图，然后做产品的 doc site，默认英文，但可以中英文切换，readme 里放截图和中文 doc 入口，readme 要求英文」。
- 文档站用 VitePress（与 Typewriter Nocturne 一致）：`website/`，英文在根目录、中文在 `/zh/`，复古冲印店配色（象牙白相纸 / 胡桃木暗房、陶土橙强调色），由 `pages.yml` 发布到 GitHub Pages。不在本地装依赖（不提交 lockfile），版本号在 `package.json` 里写死。
- 截图不在本机拍：App 有一个隐藏的截图模式（`--render-screenshots`），在 GitHub Actions 上用原创样片冲印、截自己的真实窗口和刘海面板、合成场景，`screenshots.yml` 把 JPEG 提交回 `website/public/screenshots/`。公开仓库的构建产物要登录才能下载，所以截图直接提交进仓库，README 和文档站都引用同一份。
- 截自己的窗口用 `CGWindowListCreateImage`（自己的窗口不需要屏幕录制权限；按名字动态取，避开 macOS 14 的弃用提示），拿不到时退回 `cacheDisplay`；纯 SwiftUI 的场景用 `ImageRenderer` 出 2 倍图。

### D30 · 大头贴机先选相框
- 布帘拉上后停在「选相框」：黄铜橱窗里的样张、黄铜箭头、四格条 / 四宫格与黑白 / 彩色两个拨杆开关、投币「开始」。样张用暖灰占位格和成片同一套 `PhotoComposer` 合成，所见即所得。
- 黑白用专门调过的 `booth-silver-400`（照相亭黑白 400），而不是设计稿里写的 `silver-400`：前者是闪光直打的高反差，更像照相亭；装着黑白卷时尊重用户的选择。彩色同理：默认胶卷换成 `booth-flash-400`，装着自己挑的彩色卷就用它。
- 按下「开始」才开摄像头、看门狗才开始计时：挑相框可以慢慢来，摄像头灯也不会白亮着；任何时候仍然能离开（D17）。
- 这次的选择写回设置（默认相框、版式、黑白），下次从这里开始；设置里的「默认相框」就是同一个值。

## 2026-11-23

### D29 · 从照片冲印
- 除了拖图片到刘海，还可以从「文件」（`NSOpenPanel` 多选）或「照片」图库（`PhotosPicker`，不需要照片库权限）选图，每张用当前胶卷、相纸和默认模板冲印，从刘海逐张出片。

### D28 · 摄像头可选（含虚拟摄像头）
- 设置里列出内建、外接（含以 Camera Extension 形式提供的虚拟摄像头，如 OBS）和 iPhone 连续互通摄像头；自拍与大头贴机都用所选设备，设备拔掉时回落到默认摄像头并提示。

### D27 · 相册四种看法 + 搜索
- 软木板（胡桃木框、凸字标签带、图钉与胶带的松散拼贴）、卡片盒（复刻参考图）、胶卷（光台上的胶片条 + 放大镜，参考照相亭的「精选照片条」橱窗）、日历（复古挂历，参考 Little Still 的月历回顾）。
- 底部 A–Z 检索条去掉，换成右上角搜索框：题字、标签、地点、胶卷、日期、拼音、首字母都能搜。模式切换用 Blender 渲染的小图标。

### D26 · 贴纸与模板全部程序化绘制
- 贴纸（徽章、印章、旧物、胶带、凸字标签、表情）和相纸模板（毛边、邮票、日期机、胶片框、70 年代条纹、照相馆卡纸、四宫格 / 四格条主题……）都用 Core Graphics 画：原创、没有版权问题、任意分辨率都清晰，屏幕和导出用同一套代码。

### D25 · 装饰是非破坏性的，屏幕与成片同源
- 贴纸、涂鸦、模板、题字字体、地点、标签、拍摄时间都以数据存在 `PhotoRecord` 里（旧照片库照常读取），成片随时从底片重新合成。
- `PhotoComposer` 分成「照片下面」与「照片上面」两层；屏幕上的 `PrintSurface` 用同样两层夹住显影中的照片，所以屏幕上看到的就是导出的样子。

### D24 · 滤镜引擎升级，影调对标经典胶片但不用品牌名
- 仓库所有者要求「滤镜要好看，有富士那种相纸和色调、科达胶卷那种影调」。配方加入每通道曲线、八色相带 HSL、阴影雾化、高光柔和过渡与肤色保护；15 卷重调并新增 11 卷（人像、金黄、艳色、钨丝、薄荷、常青、日常、晶亮即显、粗粒 / 细腻黑白、照相亭黑白）。
- 名字全部原创（CLAUDE.md §4）；对标关系只写在 `docs/DESIGN.md` 里供调色参考。
- 调色时用 `scripts/film/preview_looks.py`（配方数学的 numpy 移植）在本机测试照片上出样张对比；这不是构建 App，构建与测试仍然只在 CI 上。

### D23 · 相纸规格可以选
- 6 种：方形即显、迷你即显（54×86）、宽幅即显（108×86）、冲印小照（3:2 白边）、四格条、四宫格。比例参考市面上常见的即显相纸与大头贴，名字原创。
- 即显相机在刘海里切换相纸；大头贴机在「选相框」时选四格条或四宫格。胶卷有推荐相纸，但装胶卷不会自动改相纸。

### D22 · 卡片盒改为 Blender 渲染的 2.5D 分层（取代 D12 的实时 SceneKit 抽屉）
- 仓库所有者认为实时渲染的抽屉不好看，要求「立体复刻」参考图。改为用本机 Blender（命令行、Cycles）照参考图建模渲染：整盒一层、前板与侧板一层（让照片从盒子里升起时被挡住），分隔卡标签的位置导出为热区坐标。
- 原因：路径追踪的木纹、软阴影和卡片细节远好于 SceneKit 实时渲染，而且渲染结果在提交前就能看到、能逐轮修改；照片卡片本身仍是 SwiftUI，可以动画、点击、搜索。
- Blender 脚本在 `design/blender/`，可以重复生成。

### D21 · 在程序坞显示图标
- 默认是普通 App（有程序坞图标和主菜单，文本框里的拷贝粘贴等编辑命令正常），点程序坞图标打开相册；设置里可以关掉，回到只在菜单栏和刘海里的样子。

### D20 · 刘海遵循灵动岛的比例
- 平时与刘海一样大；短提示只在刘海两侧各伸出一小截（紧凑），长提示向下长出一条（横幅），不再出现横贯屏幕顶部的黑条；每次启动有一个 1.6 秒的「营业中」问候。
- 自拍取景器的高度由内容推出来，修复快门一排被裁掉的问题。

### D19 · 复古，不是手绘
- 仓库所有者明确：「我不要手绘风格，我要的是复古」。Little Still、MySketchBooth 只借鉴功能（贴纸、模板、照片条展示、日历、心情 / 地点 / 标签），视觉语言来自真实老物件：胶片、相纸、黄铜、胡桃木、软木、凸版印刷、打字机、日期机数码字、70 年代配色。
- 设计规范与跨模块接口集中写在 `docs/DESIGN.md`。

### D17 · 覆盖层安全规则（任何情况下都能退出）
- 需要系统权限的功能（自拍、大头贴机）必须在显示任何覆盖层**之前**完成权限请求；被拒绝时用普通窗口说明原因。
- 全屏覆盖层的窗口层级必须低于菜单栏（`.floating`），保证菜单栏里的「退出 Nocchi」可点；必须有可见的离开按钮，并响应 Esc / ⌘Q。
- 所有等待外部设备的步骤（拍照）都有超时，长流程有看门狗；白屏闪光这类高层级窗口必须保证被撤掉。

### D16 · 刘海暂存架
- 参考 Dropover：拖相片到刘海 = 暂存（从桌面收起，仍在相册）；从暂存架拖出 = 成片文件；从 Finder 拖图片到刘海 = 冲印。
- 文件拖放靠全局鼠标监听 + 拖拽剪贴板计数判断「有东西正在被拖」，只在刘海附近时让面板接收拖放，平时依旧点击穿透。

### D15 · 相纸精细化，屏幕与成片同源
- 纸面、内凹窗口、药包隆起、字体等细节同时实现在 `NocchiUI.PrintSurface`（屏幕）与 `PhotoComposer`（导出），几何由 `PrintGeometry` 共用；只有光面高光是屏幕专属（像真实相纸在灯下的反光）。
- Mac 桌面相片也改用 `PrintSurface`，两端只有一份相纸实现。

### D14 · 直接在 main 上开发；用 GitHub Actions 发行版本
- 仓库所有者决定：之后的改动直接推送到 `main`（`develop` 停用）。
- 推送 `vX.Y.Z` 标签触发 `release.yml`：测试 → 构建 → 打包 → 创建 GitHub Release。

### D13 · App 图标：手写矢量，macOS 圆角瓷砖规格，复古相机为主体
- 不突出刘海元素；主体是原创的复古旁轴式即显相机（香槟金属 + 黑色颗粒皮革 + 陶土橙快门帽），做旧毛边相纸从机顶升起、不出画框；胡桃木底与仓库所有者以往的图标风格一致。
- 源文件 `design/icon/nocchi-icon.svg`（由 `generate-icon.py` 生成）就是 macOS 图标；iOS 满版图标由 CI 从同一文件派生。

### D12 · 照片卡片盒用 3D 建模（SceneKit）
- 木质抽屉、立着的相片卡片、A–Z 分隔标签、桌上的照片堆都是真实 3D 物体：PBR 材质、柔和阴影、环境光遮蔽、相片表面有光泽涂层。
- 抽出 / 放回 / 叠放都是 3D 动画；首字母检索与「全部放回」是叠在场景上的 SwiftUI 控件。

### D11 · 相机用「分层建模」（2.5D），不用一张平面图
- 机身是一张高质量渲染图，镜头、快门键、闪光灯各自是独立的一层：镜头里是实时取景 + 玻璃镀膜反光（随手机倾斜移动），快门键能按下去，闪光灯会亮，整台相机随设备姿态有轻微视差和真实接触阴影。
- 原因：一张平面图一眼看上去廉价；分层后每个部件都有「实物感」，而且不需要真 3D 引擎。
- 部件位置记录在 `design/camera-instant-parts.json`（归一化坐标），换机身外观时重新测量即可。

### D10 · 配色：象牙白 + 炭黑 + 细铬 + 陶土橙
- 按仓库所有者给的参考图：象牙白机身、黑色多圈纹镜头、一道细铬圈、陶土橙快门键，不用粉色。
- 代码里统一用 `Palette`（macOS：`macOS/Nocchi/App/Palette.swift`）。
- 第二种可选外观是 80 年代方盒款（黑色机身 + 香槟银面板）。参考图是宝丽来 600 系列的标志性外观，所以做成同时代风格的原创机身：不带彩虹条和文字 logo，比例与细节不同。

### D9 · 参考「复古拍立得」网页玩法，取其精华
- 采用：默认题字「我可以见你吗？」+ 日期（可在设置里改，也可以每张单独改）；照片堆（新照片在最上层，旧照片被挤到一边）；相纸米黄底 + 暗角 + 柔边（新增 `edgeSoftness` 效果）；镜头与实时取景严丝合缝。
- 不采用：从音效网站扒音效（版权不清）——音效继续用程序合成。

### D8 · 美术素材全部原创，由 Codex 生成
- 参考图只用来对齐质感、材质、光影与配色；生成时明确要求原创造型、不出现任何品牌名 / logo / 文字 / 水印。
- `Ref_Image/` 是第三方图片（社交平台截图），不进公开仓库（`.gitignore`）。
- 生成提示词、来源与授权说明见 `docs/ASSETS.md`。

### D7 · 照片「出刘海」后飘进右上角的照片堆
- 出片 → 在刘海下方停一下（可以马上抓住甩）→ 没人拿就飘进屏幕右上角的照片堆。
- 被拖到别处的照片离开照片堆，停在用户放的位置（靠近屏幕边缘会像冰箱贴一样吸住）。

### D6 · 屏幕快门默认只响应专门的快捷键
- 回答构想文档「待定问题 1」：默认只有 ⌃⌥⌘S（或刘海面板上的「屏幕快门」）才冲印，日常截图不受打扰。
- 设置里可以开启「接管系统截图」，用 Spotlight 元数据监听 ⇧⌘3/4/5 的新截图。

### D5 · 胶卷张数只做「仪式感」计数
- 回答「待定问题 2」：每卷有张数，拍完自动换新卷并提示，不阻止拍摄。以后可加「严格模式」。

### D4 · 胶卷色调 = 参数配方运行时烘焙成 3D LUT
- 不打包第三方 LUT（许可证复杂）；15 卷内置胶卷都是原创参数（`FilmStocks.json`）。
- 支持导入用户自己的 `.cube`（校验大小、格点、数值），也能把任意胶卷导出成 `.cube`。

### D3 · 音效全部程序合成
- 快门、马达、叮、倒数、投币、撕纸等由 `SoundSynth` 实时合成，没有音频版权问题，安装包更小。

### D2 · 两个 App 分开实现，共享一个内核包
- `macOS/`（刘海出片口）与 `iOS/`（灵动岛出片口）是两个独立工程、各自的界面与交互。
- 与平台无关、可测试的逻辑放在 `Packages/NocchiKit`，两个 App 共用。

### D1 · GitHub Actions-Only CI + XcodeGen
- 本地不构建、不测试；工程文件由 `project.yml` 在 CI 中生成，不入库，避免 `.xcodeproj` 冲突。
- macOS 产物为 ad-hoc 签名 zip，iOS 产物为未签名 ipa。正式签名与公证需要在 GitHub Secrets 中配置证书后再加。
- 分支：最初是 `develop` → PR → `main`，现已改为直接在 `main` 开发（见 D14）。
